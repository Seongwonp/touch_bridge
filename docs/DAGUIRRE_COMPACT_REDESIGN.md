# Touch Bridge — DAguirreAg 기반 소형 프레임 재설계안

> 작성일: 2026-07-21
> 베이스: [DAguirreAg/CNC-pen-plotter](https://github.com/DAguirreAg/CNC-pen-plotter) (GitHub, 네이티브 GRBL)
> 목표: 이 XY 플로터를 Touch Bridge용 **소형 XYZ 정면-누름 갠트리**로 개조하는 실행 스펙.
> 관련: [HARDWARE_FRAME_MODEL_RESEARCH.md](HARDWARE_FRAME_MODEL_RESEARCH.md), [HARDWARE_MIGRATION_PLAN.md](HARDWARE_MIGRATION_PLAN.md), [HARDWARE_TASKS.md](HARDWARE_TASKS.md)
> 코드(lib/)는 수정하지 않았다. 하드웨어 설계·구매 기준 문서다.

## 원본 DAguirreAg 구성 (이번 세션 GitHub 확인)

| 항목 | 원본 |
|---|---|
| 컨트롤러 | Arduino UNO + **CNC Shield V3.0** + **A4988 ×3** |
| 모터 | NEMA17 ×3 → **X축 2개(듀얼, STEP/DIR 공유) + Y축 1개** |
| 전원 | 12V 5A |
| 벨트/풀리 | GT2 5mm 벨트, 20T 5mm보어 풀리 ×3 |
| 가이드 | 8mm 강봉(리니어) — **500mm ×2, 250mm ×2**, 8mm 리니어베어링, 8mm 봉홀더 |
| 냉각 | 12V 팬 |
| Z(펜업) | **명시 없음** — 사실상 2축 XY 플로터 (Z는 우리가 신설) |

핵심: 원본은 **X를 2모터로 강성**을 얻고 **Z가 없다**. Touch Bridge는 정반대로 **모터 3개를 X/Y/Z에
1개씩** 써야 하므로, 아래 "변경 1"이 이 재설계의 뼈대다.

## 변경 요약 (원본 → Touch Bridge)

| 변경 | 원본 | Touch Bridge | 이유 |
|---|---|---|---|
| **1. 축 배치** | X 듀얼(2) + Y(1), Z 없음 | **X(1) + Y(1) + Z(1)** | 모터 3개로 3축. 누름축 Z 신설이 필수 |
| **2. X 강성 보강** | 듀얼모터로 확보 | **모터 1개 + 8mm 봉 2개 병렬 + (가능하면) MGN12 레일** | 모터를 Z로 뺐으니 강성은 가이드로 확보 |
| **3. 드라이버** | CNC Shield + A4988 ×3 | **TB6600 ×3 직결 (실드 제거)** | [HARDWARE_MIGRATION_PLAN.md](HARDWARE_MIGRATION_PLAN.md) 확정. TB6600은 외장형이라 실드에 안 꽂힘 |
| **4. 크기** | 500/250mm 봉 (대형 A3급) | **X≈200~250mm, Y≈150mm 봉** | 전자레인지 버튼면(~150×120mm 목표)에 맞춰 축소 |
| **5. Z 누름부** | 없음/서보 | **NEMA17 + T8 리드스크류 + 스프링 완충 터치팁** | 실제 물리 버튼 누름 + 과압 방지 |
| **6. 자세** | 수평 데스크 | **수직(패널 정면) 마운트** | 가전 버튼면이 수직/경사 |
| **7. 전장** | 실드 케이스 | **오프-갠트리 TB6600 박스 자체 제작** | 필터 C |

## 1. 축 배치 & 목표 치수

```
        ┌─────────────── X (좌우, 1×NK1704S + GT2 벨트) ───────────────┐
        │  [X 캐리지] ── 그 위에 Y ─┐                                    │
        │                          [Y 캐리지] ── 그 위에 Z 누름모듈      │
        │                                         │                      │
        │                                     [Z 리드스크류]             │
        │                                         ▼ (앞으로 누름)         │
        └──────────────── 전자레인지 버튼 패널(수직면) ─────────────────┘
```

- **작업영역 목표**: X ≈ 150mm, Y ≈ 120mm (버튼 패널 실측 후 확정 — 아래 "다음 단계").
- **봉 길이(권장 시작값)**: X 가이드봉 ~200~250mm(스트로크 150 + 캐리지/여유), Y 가이드봉 ~150~180mm.
  원본 500/250mm에서 **잘라서** 사용(강봉은 파이프커터로 절단 가능).
- **적층식(스택) 구조**: X가 Y를 싣고, Y가 Z를 싣는 Cartesian 3층. 클래식 GRBL(Cartesian)과 1:1로 맞음.

> 주의(필터 B): Y와 Z가 X 위에 얹혀 수직 자세로 움직이므로 **이동 질량을 최대한 가볍게** 한다.
> Z 모듈이 가장 무거우니 NK1704S 대신 Z만 소형 스텝을 쓸지 여부는 힘 테스트 후 결정(현재는 3축 동일 유지 가정).

## 2. 드라이버 & 배선 변경 (실드 → TB6600 ×3)

CNC Shield/A4988을 제거하고 **TB6600 3개를 Arduino Uno의 GRBL 핀에 직결**한다.
GRBL 기본 핀맵 기준:

| 축 | GRBL STEP 핀 | GRBL DIR 핀 | 공통 |
|---|---|---|---|
| X | D2 | D5 | Enable = D8 (전 축 공통) |
| Y | D3 | D6 | |
| Z | D4 | D7 | |

TB6600 결선(각 드라이버):
- `PUL+` ← Uno STEP 핀, `DIR+` ← Uno DIR 핀, `ENA+` ← Uno D8(또는 항상 활성)
- `PUL- / DIR- / ENA-` ← Uno GND (공통) — **공통 GND 필수** ([HARDWARE_TASKS.md](HARDWARE_TASKS.md))
- Uno는 5V 로직이라 TB6600 옵토 입력과 대체로 호환(3.3V ESP32가 아니라 Uno가 직접 GRBL을 돌리므로 레벨시프터 불필요). ESP32는 UART 브릿지 쪽에만 레벨시프터 적용.
- TB6600 DIP: 전류는 NK1704S 정격 이내, 마이크로스텝은 GRBL `$100~$102` steps/mm 계산과 함께 기록.
- 모터 전원 12V는 **배럴잭 별도 + 퓨즈**, 대용량 전해캡 병렬.

> 이 변경으로 원본의 12V 5A는 TB6600 3개 기준 **여유 있는 정격(예: 12V 6~10A)** 으로 재산정 권장.

## 3. Z 누름 모듈 (신설 — 안전 핵심)

[HARDWARE_FRAME_MODEL_RESEARCH.md](HARDWARE_FRAME_MODEL_RESEARCH.md) 3장 6겹 안전 구성을 그대로 적용:

1. NK1704S + **T8 리드스크림(셀프락)** → 전원 끊겨도 자중 낙하 억제
2. **스프링 완충 + 전도성 터치팁** (natester 프로브 바디 응용) → 과압 물리 상한
3. 팁 NC 접점 → GRBL `$6` 프로빙("버튼 닿음" 하드웨어 확인)
4. Z 상단 마이크로스위치 → 하드리밋
5. 앱 매핑 프로필 `pressDepthZ` 소프트 상한 + GRBL `$132`
6. TB6600 ENA 끊는 물리 **E-STOP(NC)**

Z 스트로크는 짧게(예: 15~25mm)로 잡아 이동질량·낙하위험을 줄인다.

## 4. 출력·구매 델타 (원본 대비)

**원본 STL 재사용 가능(치수만 축소/확인):**

- 풀리 홀더, 8mm 봉 서포트, 벨트 텐셔너

**새로 필요(원본에 없음):**

- 수직 마운트 베이스/스탠드 또는 전자레인지 부착 브래킷
- TB6600 ×3 전장 박스(자체 설계)
- 단일 X모터 캐리지(듀얼→싱글 변경분)

**구매 부품:**
- NK1704S ×3(보유), **TB6600 ×3**(A4988 대체), 12V PSU(정격 상향), 배럴잭+퓨즈
- GT2 5mm 벨트 + 20T 풀리 ×2(X,Y), 8mm 강봉(원본 것 절단 재사용), LM8UU
- **T8 리드스크림 + 너트 + 유연커플러**(Z), 스프링, 전도성 터치팁, 마이크로스위치 ×4~6
- (권장 업그레이드) MGN12 레일 ×2로 X 강성 보강, BSS138 레벨시프터(ESP32 UART용), E-STOP 버튼

## 5. 조립·검증 순서 (요약)

1. NK1704S 1개 + TB6600 1개 단일축 GRBL 구동·`$100` 튜닝 ([HARDWARE_TASKS.md](HARDWARE_TASKS.md) 시운전 체크리스트 준용)
2. X(싱글모터+봉2) 조립 → homing
3. Y 적층 → 2축 좌표 이동 확인
4. Z 리드스크림 모듈 + 스프링/프로브 조립 → 프로빙 접점 확인
5. 수직 스탠드에 세워 중력 부하 하에서 재-homing/반복정밀 확인
6. E-STOP → TB6600 ENA 차단 즉시정지 확인
7. 앱 개발자 콘솔에서 `$H`/jog/raw G-code/STOP → 사진매핑 좌표 실행

# 부록 A. "3D 설계 못 하는데 AI 있어?" — 현실적 경로

**결론 먼저**: 모터 마운트·브래킷 같은 **기능성 기계 부품**은 치수 정확도가 생명이라, 그림/텍스트로
메시를 뽑는 생성형 3D AI(**Meshy, Tripo, Rodin, Luma**)는 **적합하지 않다**(치수 부정확·출력해도 안 맞음).
그건 캐릭터·소품용이다. 대신 아래 순서가 현실적이다.

### 경로 1 — 설계 안 하고 "재사용 + 파라미터 조절" (가장 빠름, 추천)
- DAguirreAg STL을 **그대로** 쓰고, 크기만 바꾸면 되는 건 **Thingiverse Customizer / Printables**의
  파라메트릭 모델로 슬라이더만 조절 → 설계 지식 0.
- 표준 부품(NEMA17 마운트, 8mm 봉홀더, GT2 텐셔너)은 이미 검증된 STL이 많으니 **직접 안 그려도 됨**.

### 경로 2 — 코드형 CAD를 "AI가 대신 작성" (정밀 부품용, 실질적 최선)
- **OpenSCAD**(무료): 부품을 코드로 그리는 툴. 당신이 "NK1704S 마운트에 리드스크림 구멍 추가" 식으로
  말하면 **AI(나 또는 ChatGPT)가 .scad 코드를 써 주고**, 당신은 붙여넣고 F6 → STL 내보내기만 하면 된다.
  → 이게 "설계 못 하는 사람을 위한 진짜 AI 3D설계"다. **내가 지금 바로 코드 만들어 줄 수 있다.**
- **CadQuery**(파이썬): 동일 원리, 좀 더 프로그래밍적. 역시 AI가 코드 작성 가능.

### 경로 3 — 진짜 텍스트→CAD AI
- **Zoo Text-to-CAD** (text.zoo.dev): 문장으로 CAD 생성, **STEP** 내보내기, 무료 티어 존재.
  브래킷·플레이트류에 쓸 만하다(복잡 조립품은 아직 한계).

### 경로 4 — 초보용 드래그&드롭
- **Tinkercad**(무료, 브라우저): AI는 아니지만 블록 쌓기 수준으로 쉬움. 단순 마운트 플레이트엔 충분.
- 조금 배울 의향이 있으면 **Fusion 360**(개인 무료) — 생성형 설계 기능도 있으나 이 프로젝트엔 과함.

### 바로 쓸 수 있는 OpenSCAD 스타터 (NK1704S/NEMA17 마운트 플레이트)
> **시작 템플릿**이다. 인쇄 전 실제 모터의 **볼트 간격(31.0mm)·보스 지름·바디 42.3mm**를 반드시 실측 대조.

```scad
// NK1704S (NEMA17) 마운트 플레이트 — Touch Bridge 스타터
// 단위 mm. 인쇄 전 실측 대조 필수.
nema_body   = 42.3;   // 모터 바디 폭
hole_pitch  = 31.0;   // 볼트홀 정사각 간격 (NEMA17 표준)
bolt_d      = 3.4;    // M3 여유
center_bore = 23;     // 중심 보스/축 여유
plate       = 6;      // 판 두께
margin      = 6;      // 모터 둘레 여백

size = nema_body + 2*margin;

difference() {
  translate([-size/2, -size/2, 0]) cube([size, size, plate]);          // 판
  translate([0, 0, -1]) cylinder(h = plate + 2, d = center_bore, $fn = 64); // 중심 보어
  for (x = [-hole_pitch/2, hole_pitch/2])                               // 볼트홀 4개
    for (y = [-hole_pitch/2, hole_pitch/2])
      translate([x, y, -1]) cylinder(h = plate + 2, d = bolt_d, $fn = 32);
}
```

OpenSCAD 설치 → 붙여넣기 → F5(미리보기)/F6(렌더) → File > Export > STL → 슬라이서에서 인쇄.
필요하면 이 플레이트에 **봉 구멍·리드스크림 구멍·벨트 클램프**를 추가한 버전도 코드로 만들어 줄 수 있다.
