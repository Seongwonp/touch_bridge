## 당사자 평가 전 추가 확인 필요 항목

실기기 TalkBack 켜고 직접 확인해야 하는 것들:

- [ ] **TalkBack 완주 테스트** — 홈 → 기기 선택 → 음성 명령 → 확인 → 완료 → 비상 정지
- [ ] **TalkBack 액션 메뉴** — 기기 카드에서 "음성 명령 시작" 액션 노출 확인 (손가락 위→오른쪽 스와이프)
- [ ] **PageView 전환** — TalkBack 활성 시 FooterNavHint 이전/다음 버튼으로 기기 카드 전환 확인
- [ ] **BottomSheet 포커스** — ControlModeSheet 열릴 때 첫 버튼("음성으로 제어")에 TalkBack 포커스 이동 확인
- [ ] **음성 자동 시작** — ControlModeSheet에서 "음성으로 제어" 선택 시 화면 진입 즉시 녹음 시작 확인
- [ ] **첫 실행 다이얼로그** — SharedPreferences 초기화 후 앱 실행 시 "처음 오셨나요?" 다이얼로그 TalkBack 낭독 확인
- [ ] **200% 폰트** — 시스템 설정 → 글자 크기 최대 → 앱 실행 → 버튼 텍스트 잘림 없음 확인
- [ ] **비상 정지 음성** — "멈춰" 발화 시 화면 어디서든 비상 정지 화면 진입 확인
