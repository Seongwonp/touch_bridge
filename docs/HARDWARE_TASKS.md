# 하드웨어 작업 및 안전 체크리스트

이 문서는 Touch Bridge 하드웨어를 설치·운영·유지보수할 때 반드시 작업자가 직접 수행해야 하는 물리적 작업과 안전 권고사항을 정리한 체크리스트입니다.

## 요약(핵심 우선순위)

1. 전원 분리 및 퓨즈 추가(NK1704S/TB6600 모터 전원은 12V 배럴잭으로 별도 공급)
2. ESP32(3.3V) ↔ Arduino(5V) 레벨 시프터 적용 (UART 라인)
3. 공통 GND 연결 확인
4. 비상정지(하드웨어 E‑STOP) 회로 구성 — MCU 불능 상태에서도 파워 차단 가능하도록 구성
5. 모터 드라이버 ENABLE/FAULT 라인으로 즉시 정지 구현
6. 전류·온도 센서로 과부하·과열 모니터링
7. XYZ 각 축 리미트 스위치 및 GRBL homing 설정 확인

---

## 현재 하드웨어 방향(2026-07-19)

- X축: NK1704S 42각 스텝모터 1개 + TB6600 1개
- Y축: NK1704S 42각 스텝모터 1개 + TB6600 1개
- Z축: NK1704S 42각 스텝모터 1개 + TB6600 1개
- 제어: Arduino Uno + GRBL 유지
- 통신: ESP32가 앱 명령을 받아 Arduino Uno GRBL로 UART 전달
- 전원: MCU 전원과 모터 전원을 분리하고, 모터는 12V 배럴잭 입력으로 별도 공급
- 통신 확장: BLE는 기존 연결/복구 경로로 유지, 가정용 고정 장치 기준 Wi-Fi HTTP/WebSocket 제어 추가 검토

## 배선(Serial)

- 권장: ESP32 Serial2 (RX=16, TX=17) ↔ Arduino RX/TX (또는 별도 Serial 포트)
  - ESP32 TX (GPIO17) -> LVTTL 레벨시프터 -> Arduino RX (D0)
  - ESP32 RX (GPIO16) <- Arduino TX (D1) through level shifter if needed
  - 공통 GND 필수(ESP GND ↔ Arduino GND ↔ 모터 전원 GND)
- 주의: Arduino Uno의 하드웨어 Serial(Serial0)은 USB 연결과 공유됩니다. 업로드/디버깅 중 충돌 방지 필요.
  - 가능하면 Serial1/하드웨어 UART가 더 많은 보드를 사용하거나 SoftwareSerial을 사용

## 레벨 시프터

- 3.3V -> 5V 신호(ESP RX 입력으로 들어오는 Arduino TX)는 일반적으로 3.3V가 논리 HIGH로 인식되지만 안정성을 위해 양방향 로직 레벨 시프터(BSS138 기반) 사용 권장.
- ESP TX(3.3V) -> Arduino RX(5V) 방향은 반드시 레벨시프터 사용 권장.

## 전원 및 전류 보호

- 스텝모터는 높은 돌입전류를 가집니다. MCU 전원과 모터 전원 분리 권장.
- 권장: 모터 전원용 퓨즈(정격은 모터 소비 전류의 150% 권장) 및 폴리퓨즈 사용
- 전원 라인에 대용량 전해 캐패시터(예: 470uF~2200uF) 및 세라믹 캡을 병렬로 배치하여 전압 강하를 완화
- TB6600 3개가 같은 12V 전원을 공유할 경우 전원 어댑터 정격에 여유를 둔다.

## 비상 정지 회로 (권장 구현)

1. 하드웨어 E‑STOP을 메인 모터 전원 라인(또는 모터 드라이버 ENABLE 핀) 직렬로 배치.
2. E‑STOP은 NC(정상 닫힘) 방식 권장 — 스위치 누름 시 회로가 열려 전원 차단.
3. 메인 전원 차단용으로는 파워 릴레이(또는 컨택터)를 사용. 릴레이는 MCU 제어가 아닌 외부 물리 버튼으로 제어되거나 두 단계 논리(안전 릴레이)로 구성.
4. 만약 릴레이 대신 MOSFET를 쓴다면, E‑STOP이 즉시 Gate를 드라이브하여 MOSFET를 차단하는 독립 회로를 구성(절대 MCU에 의존하지 않음).

> 권고: 안전 규정(산업 표준)이 적용되는 환경에서는 인증된 안전 릴레이 및 설계자·기술자 검토 필요.

## 모터·드라이버 권장

- 현재 우선안: NK1704S 42각 스텝모터 3개 + TB6600 3개
- A4988/DRV8825는 단일 축 구동 테스트나 저부하 검증용으로 사용할 수 있으나, 발표/실기기 안정성 기준에서는 TB6600을 우선한다.
- TB6600 DIP 스위치의 전류 제한과 마이크로스텝 설정은 모터 정격과 GRBL steps/mm 계산에 맞춰 기록한다.
- 모터 드라이버의 ENABLE/RESET/FAULT 라인을 E‑STOP 및 MCU 즉시 제어 가능하도록 배선
- Z축은 누름 힘이 필요한 축이므로 스프링 완충, 하단 리미트 스위치, 전도성 터치팁을 함께 고려한다.

## 센서(권장)

- 전류 센서: ACS712 또는 INA219류로 실시간 전류 모니터링
- 온도 센서: 스텝모터/드라이버 온도 모니터링(예: DS18B20 또는 NTC)
- 센서를 통한 임계값 초과 시 MCU에서 EMERGENCY_STOP 명령 전송 및 하드웨어 차단

## 펌웨어 권고(하드웨어 연동 관련)

- E‑STOP 인터럽트 처리: 하드웨어 입력에 ISR 바인딩하여 즉시 모터 드라이버 비활성화
- MCU 재시작 시 안전모드(모터 파워 OFF)로 시작
- UART 버퍼/동기화: GRBL `ok`, `error`, `ALARM` 응답을 명확히 앱 로그로 전달하도록 ACK 로직 강화
- 전력 오류 감지(입력 전압 모니터링) 시 안전한 상태로 전환
- GRBL 설정값 `$100~$132`, 축 방향, homing 방향, 리미트 스위치 동작을 새 기구부 기준으로 다시 튜닝

## 시운전 체크리스트

1. 전원 연결 전 회로·배선 재확인(GND 포함)
2. ESP/Arduino 간 레벨시프터 설치 확인
3. 모터 전원 분리(테스트 시에는 전류제한 전원 사용)
4. 시리얼 통신 확인: Serial Monitor로 GRBL/UNO 출력 확인
5. 각 축 단독 jog 테스트: `G91` -> `G1 X/Y/Z...` -> `G90`
6. `$H` homing 및 각 축 리미트 스위치 동작 확인
7. 앱 개발자 콘솔 또는 nRF Connect로 BLE 연결 후 raw G-code 전송 확인
8. Wi-Fi API를 추가한 경우 HTTP/WebSocket 명령과 BLE 명령이 같은 GRBL 경로로 들어가는지 확인
9. 사진 매핑 좌표에서 X/Y 이동 후 Z축 누름 시퀀스 확인
10. 비상정지 버튼 누름 시 즉시 모터 정지 확인
11. 장시간 테스트(부하·발열)로 온도/전류 상승 여부 확인

## 권장 부품(예시)

- 양방향 로직 레벨 시프터(BSS138 기반)
- 전류 센서: ACS712 5A/20A 모듈
- 비상정지: 대형 Mushroom E‑STOP 스위치 + 안전 릴레이 또는 10A 이상 릴레이 모듈
- 퓨즈/폴리퓨즈: 모터 정격에 맞춰 선택
- 모터 드라이버: TB6600 3개(X/Y/Z), A4988/DRV8825는 보조 테스트용
- 리미트 스위치: 최소 3개, 가능하면 6개
