# Touch Bridge 3분 데모 스크립트

> 2026-06-25 갱신: 하단 바에 독립 음성/연결 탭이 없습니다. 음성은 홈의 "말하기" 버튼에서 시작하고, 기기 추가/연결/매핑은 보호자 모드의 기기 관리 흐름에서, 비상 정지는 하단 "비상" 탭에서 접근합니다. 자세한 모드별 권한은 [ACCESSIBILITY_COPY_GUIDE.md](ACCESSIBILITY_COPY_GUIDE.md) 6장 참고.

## 시연 전 체크리스트
- [ ] 하드웨어: 12V 인가, `$H` 홈 복귀, 매핑 테스트 터치 검증 완료 (REPRO_RUNBOOK 2-1/6-1)
- [ ] 백엔드 기동 + `AI_BACKEND_URL`(포트 8000) 확인, BLE 연결 확인
- [ ] TTS 볼륨 최대 (발표장 소음 대비, 필요 시 외부 스피커)
- [ ] 백업: BLE 실패 시 개발자 모드 dry-run 로그 시연 + 사전 촬영 영상
- [ ] 안대 또는 "화면을 보지 않겠다" 선언 준비

## 0:00 ~ 0:20 문제 제시
- "시각장애인 사용자는 터치패널 가전에서 버튼 위치 탐색 중 오작동이 자주 발생합니다."
- "Touch Bridge는 앱 명령을 받아 하드웨어가 대신 물리 터치를 수행합니다."

## 0:20 ~ 0:40 시스템 구조 + 모드 소개
- "앱에서 명령 생성 → BLE → ESP32 → 물리 동작"
- "앱은 접근성 UX와 안전장치, 하드웨어는 실제 터치 수행 담당"
- 하단 바를 가리키며: "일반 사용자 모드는 홈, 비상 정지, 설정 세 개뿐입니다. 기기 추가나 연결처럼 구조를 바꾸는 기능은 보호자 모드에서만 보입니다."

## 0:40 ~ 1:20 시나리오 1 (보호자 모드 — 기기 추가/연결/매핑)
1. 설정 > 보호자 모드 ON
2. 하단 바에 "기기 관리" 탭이 새로 나타나는 것을 보여준다
3. 기기 관리 진입 → QR/BLE/NFC 중 하나로 연결
4. 사진 매핑으로 버튼 위치 등록 (또는 기존 저장된 매핑 확인)
5. 보호자 모드 OFF로 전환 → "기기 관리" 탭이 사라지고 하단 바가 다시 홈/비상/설정으로 단순화되는 것을 확인

## 1:20 ~ 2:00 시나리오 2 (사용자 모드 — 음성 조작)

**연출: 시나리오 2는 발표자가 화면을 보지 않고(또는 안대를 쓰고) 수행한다.**
- 진입 TTS를 청중이 듣게 한 뒤: "지금 저는 화면을 보지 않았습니다. 들었고, 확인했고, 실행했습니다."
- 하드웨어가 실제 버튼을 누르는 순간 3초간 멘트 없이 기계 동작만 보여준다 (시연의 정점).
- 이중 탭 확인 시연 시 멘트: "한 번 탭하면 실행되지 않습니다. 먼저 무엇을 누르려는지 음성으로 알려줍니다."

1. 홈 화면에서 활성 기기(예: 전자레인지) 확인 — 진입 TTS로 기기명/상태 안내
2. 홈의 큰 "말하기" 버튼 탭
3. "전자레인지 2분 30초 돌려줘" 명령
4. 버튼 시퀀스 생성 및 BLE 전송 로그 확인
5. 타이머/진행 화면 진입 확인

## 2:00 ~ 2:25 시나리오 3 (수동 조작 + 이중탭 확인)
1. 홈 → 기기 선택 → 수동 제어 진입
2. 시간 입력 + 시작 버튼
3. 이중탭 확인 UX 시연(첫 탭 안내, 둘째 탭 실행)

## 2:25 ~ 2:45 시나리오 4 (비상 정지)
1. 하단 "비상" 탭 진입 (사용자/보호자 모드 어디서든 항상 보임)
2. 작동 중 비상정지 버튼 3초 홀드 또는 "멈춰" 음성 명령
3. 즉시 정지 및 완료 화면 확인

## 2:45 ~ 2:55 정량 지표 제시

## 시연 실패 시 대응

| 상황 | 대응 |
|---|---|
| BLE 연결 실패 | 개발자 모드 dry-run으로 "탭 → 명령 변환" 로그를 실시간 시연, 하드웨어는 사전 영상으로 대체 |
| 좌표 어긋남 | 보호자 모드 테스트 터치 화면으로 전환해 "어긋나면 이렇게 재보정합니다"로 시연을 이어감 (실패를 기능 시연으로 전환) |
| TTS가 안 들림 | 대본의 앱 음성 문구를 발표자가 직접 낭독 ("지금 앱은 이렇게 말하고 있습니다") |
| STT 인식 실패 2회 | "시끄러운 발표장은 최악의 조건"임을 인정하고 수동 조작(시나리오 3)으로 전환 — 재시도 3회 이상 금지 |
| 백엔드 미연결 | 저장된 매핑 기반 수동 제어로 전환 (AI 없이도 동작함을 오히려 강조) |
