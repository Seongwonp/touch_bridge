# Touch Bridge 3분 데모 스크립트

## 0:00 ~ 0:20 문제 제시
- “시각장애인 사용자는 터치패널 가전에서 버튼 위치 탐색 중 오작동이 자주 발생합니다.”
- “Touch Bridge는 앱 명령을 받아 하드웨어가 대신 물리 터치를 수행합니다.”

## 0:20 ~ 0:40 시스템 구조 소개
- “앱에서 명령 생성 → BLE → ESP32 → 물리 동작”
- “앱은 접근성 UX와 안전장치, 하드웨어는 실제 터치 수행 담당”

## 0:40 ~ 1:30 시나리오 1 (음성 조작)
1. 음성 화면 진입
2. “2분 30초 돌려줘” 명령
3. 버튼 시퀀스 생성 및 BLE 전송 로그 확인
4. 타이머/진행 화면 진입 확인

## 1:30 ~ 2:00 시나리오 2 (수동 조작 + 이중탭 확인)
1. 홈 → 기기 선택 → 수동 제어 진입
2. 시간 입력 + 시작 버튼
3. 이중탭 확인 UX 시연(첫 탭 안내, 둘째 탭 실행)

## 2:00 ~ 2:25 시나리오 3 (비상 정지)
1. 작동 중 비상정지 버튼 3초 홀드 또는 “멈춰”
2. 즉시 정지 및 완료 화면 확인

## 2:25 ~ 2:50 정량 지표 제시
- 설정 > 접근성 실험 지표 진입
- 다음 지표 제시:
  - 완료율
  - 평균 완료 시간
  - 비상 정지 횟수
  - 이중탭 타임아웃 횟수

## 2:50 ~ 3:00 마무리
- “핵심은 실제 물리 조작 + 접근성 안전 UX 결합입니다.”
- “남은 과제는 BLE 안정화/센서 피드백 고도화입니다.”
