# 하드웨어 마이그레이션 계획서: 28BYJ-48 → NEMA 11 (TMC2208)

이 문서는 기존의 `28BYJ-48 + ULN2003` 제어 방식에서 정밀하고 정숙한 `NEMA 11 + TMC2208` 방식으로 전환하기 위한 기술 로드맵입니다.

---

## 1. 개요 및 목적
- **기존 방식:** 28BYJ-48 (전압 구동, 감속 기어 내장) + ULN2003
- **문제점:** 심각한 발열, 낮은 내구성, 동작 유격(백래시), 정숙성 부족.
- **개선 방향:** NEMA 11 (초소형, 7Ncm 토크) + TMC2208 (정전류, 정숙성)
- **기대 효과:** 버튼 조작 신뢰성 확보, 하드웨어 소음 제거, 정밀한 위치 제어.

---

## 2. 하드웨어 배선 변경

| 구성 | 기존 (28BYJ-48 + ULN2003) | 신규 (NEMA 11 + TMC2208) |
| :--- | :--- | :--- |
| **제어 핀** | 4핀 (IN1, IN2, IN3, IN4) | **2핀 (STEP, DIR)** |
| **전원** | 5V | **12V ~ 24V (권장)** |
| **드라이버** | ULN2003 | **TMC2208** |

### 배선 상세
1. **TMC2208 연결:**
   - **STEP:** MCU GPIO → TMC2208 STEP 핀
   - **DIR:** MCU GPIO → TMC2208 DIR 핀
   - **VM:** 12V~24V 별도 전원 연결 (모터 전용)
   - **GND:** 공통 GND 필수
2. **모터 연결:**
   - NEMA 11 4개 선 → TMC2208 `A1, A2, B1, B2`

---

## 3. 펌웨어(코드) 수정 가이드

`Stepper.h` 대신 **`AccelStepper.h`** 라이브러리 사용을 권장합니다.

```cpp
#include <AccelStepper.h>

// 신규 설정: Driver 모드
AccelStepper myStepper(AccelStepper::DRIVER, STEP_PIN, DIR_PIN);

void setup() {
  myStepper.setMaxSpeed(1000);
  myStepper.setAcceleration(500);
}
```

---

## 4. 마이그레이션 로드맵

1. **부품 확보:** NEMA 11 모터(7Ncm), TMC2208 드라이버, 12V/24V 전원 공급기.
2. **프로토타이핑:** 브레드보드에서 모터 1개 구동 테스트 (AccelStepper 라이브러리).
3. **기구부 설계:** NEMA 11 규격에 맞춘 3D 프린팅 마운트 설계 및 출력.
4. **코드 이식:** 기존 가전 제어 로직(이동, 터치)을 AccelStepper 기반으로 변환.
5. **성능 튜닝:**
   - TMC2208 Vref 설정 (0.5V~0.6V 범위 내 조절).
   - 최고 속도 및 가속도 값 최적화.

---

## 5. 주의사항
- **전류 제한:** 드라이버의 가변 저항으로 모터 정격 전류를 넘지 않도록 Vref를 반드시 조정하세요.
- **열 관리:** 소형 모터이므로 외함 통기성 확보가 필요합니다.
- **전압 분리:** 5V 로직 전원과 모터 전원을 완전히 분리해야 MCU 리셋 문제를 방지할 수 있습니다.
