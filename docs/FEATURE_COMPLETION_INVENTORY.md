# Touch Bridge 기능 완성 인벤토리

> 작성일: 2026-06-26  
> 목적: 오늘 남은 작업을 기능 단위로 닫기 위해 현재 구현/테스트/실기기 검증 상태를 한눈에 정리한다.

> **2026-06-30 추가 노트**: 이 문서의 기능별 상태는 그대로 유효함 — 이후 진행한 작업은 구조 리팩토링(대형 파일 분리)과 디자인 토큰/비주얼 정리뿐이고 기능 동작은 바꾸지 않음. 매 단계 `flutter analyze`/`flutter test`(29/29)로 회귀 확인함. 자세한 내용은 `docs/WORK_LOG.md`의 2026-06-30 항목 참고.

## 상태 기준

- **완료**: 코드 구현, 기본 테스트, 문서 반영 완료.
- **불안정**: 동작 경로는 있으나 공통화/예외 처리/반응형/실기기 검증이 부족함.
- **미연결**: UI 또는 데이터는 있으나 실제 실행 경로와 연결이 약함.
- **테스트 없음**: 기능은 있으나 단위/위젯 테스트가 부족함.
- **실기기 필요**: 로컬 테스트로는 최종 판정 불가. ESP32/기구물 연결 확인 필요.

## 기능별 현황

| 기능 | 현재 상태 | 근거 | 오늘 완료 조건 |
|---|---|---|---|
| 홈 화면 | 완료 | 보호자 모드별 기기 추가 숨김, 큰 말하기 버튼, 3회 터치 음성 진입 구현 | 홈 말하기/활성 기기 흐름 회귀 확인 |
| 하단 내비게이션 | 완료 | 사용자 모드: 홈/비상/설정, 보호자 모드: 홈/기기 관리/비상/설정 | 기존 위젯 테스트 유지 |
| 기기 관리 | 불안정 | 보호자 모드 진입/추가 플로우는 있으나 화면별 권한 테스트가 제한적 | 권한 표 문서화 및 주요 흐름 수동 체크 |
| BLE/QR 연결 | 불안정, 실기기 필요 | BLE 스캔/연결 위젯 테스트 있음. 실제 기기 연결은 환경 의존 | 재현 가이드 체크리스트 유지, 실기기 연결 확인 |
| 사진 매핑 | 앱 구현 완료, 실기기 필요 | `buttonPositions` 저장, contain 좌표계, 개별/전체 테스트 터치 구현 | ESP32에서 버튼별 실제 터치 위치 확인 |
| 수동 매핑 | 앱 구현 완료, 실기기 필요 | rows/cols/origin/pitch 저장, 조이스틱, 홈 이동, 현재 위치 원점 지정, 원점 테스트 터치 구현 | 실제 원점/간격 값 보정 |
| 이미지 제어 | 앱 구현 완료, 실기기 필요 | 사진 위 마커가 저장 좌표 기반으로 표시되고 공통 실행 서비스 사용 | ESP32에서 같은 버튼 위치 실행 확인 |
| 음성 명령 | 앱 구현 완료, 실기기 필요 | 기기명 해석, 활성 기기 fallback, 모호한 명령 재질문, 공통 실행 서비스 사용 | 자연어 케이스와 실제 터치 위치 확인 |
| 코스 제어 | 앱 구현 완료, 실기기 필요 | 저장 매핑 기반 버튼 시퀀스를 공통 실행 서비스로 실행 | 코스별 실제 버튼 시퀀스 확인 |
| 비상 정지 | 완료에 가까움 | 비상 탭, 음성 명령, 긴급 화면 있음 | 실기기 STOP 전송 확인 |
| 설정/보호자/개발자 모드 | 앱 구현 완료 | 사용자/보호자/개발자 섹션 분리, 개발자 도구 별도 토글 | 배포 전 개발자 모드 제거 여부 결정 |
| 개발자 콘솔/조이스틱 | 앱 구현 완료, 실기기 필요 | ESP 선택, raw 명령, 조이스틱, 이동 단위, 속도 조절, `G91` + `G1` + `G90` 상대 이동 사용 | 명령 로그/실기기 이동 확인 |
| 반응형 UI | 불안정 | 매핑 좌표계는 안정화. 전 화면 QA는 남음 | 주요 화면별 수동 QA 체크리스트 작성 |
| 접근성/TTS/햅틱 | 불안정 | 주요 문구 정리됨. 모든 상태 전환 테스트는 부족 | 실패/재시도/권한 차단 문구 통일 |
