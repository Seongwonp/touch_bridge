# Touch Bridge HW 개발 계획

## 목표
앱 명령이 기기별 매핑 규칙에 맞게 안정적으로 하드웨어 동작으로 이어지도록 연동 완성.

## 단계별 계획

### 1단계: 프로토콜 고정 (완료 기준: 문서+코드 일치)
- 앱/ESP32/AVR 명령 형식 고정
- 고정 enum/UUID/명령 prefix 문서화
- 완료 기준:
  - 연동 문서와 앱 상수가 동일
  - 임의 문자열 하드코딩 제거

### 2단계: 기기별 그리드 적용
- 2x2/3x3 등 그리드 동적 적용 경로 정리
- `SET_GRID` 선전송 강제
- 완료 기준:
  - 그리드 크기 변경 시 동일 코드 경로로 동작
  - 범위 에러 처리 일관성 확보

### 3단계: 통합 테스트 루프
- 실기기 미연결: 앱 로그 기반 검증
- 실기기 연결: BLE -> UART -> AVR 응답 확인
- 완료 기준:
  - 음성 명령 시나리오 5개 이상 통과
  - 비상정지 포함 end-to-end 확인

### 4단계: 안정화
- BLE 재연결/타임아웃 개선
- 에러 메시지 표준화
- 완료 기준:
  - 재연결 실패 후 복구 시나리오 통과
  - 사용자 안내 메시지 일관성 확보

## 우선순위
1. 프로토콜 일치
2. 동적 그리드
3. 테스트 자동화/체크리스트
4. 안정화
