# Touch Bridge HW Docs

이 폴더는 Touch Bridge 하드웨어 저장소에서 **프로젝트 운영에 필요한 문서만** 유지한다.

## 문서 목록
- `APP_HW_PROTOCOL_KO.md`  
  앱 ↔ ESP32 ↔ AVR/GRBL 연동 규약, enum/고정값, 그리드 정책
- `PROJECT_PLAN_KO.md`  
  다음 개발 단계 계획, 우선순위, 완료 기준
- `IMPLEMENTATION_CHECKLIST_KO.md`
  단계별 체크리스트, 테스트 결과, 문서 최신화 기록
- `ESP32_BLE_CONNECTION_TEST_KO.md`
  ESP32 BLE 연결 테스트(Write/Notify)용 업로드 가이드
- `ESP32_BLE_BRIDGE_FIRMWARE_KO.md`
  ESP32 BLE↔UART 브리지 펌웨어 업로드 가이드

## 문서 관리 원칙
- 과거 로그/심사자료는 앱 저장소 또는 별도 아카이브에 보관
- 이 폴더에는 현재 개발/연동에 직접 쓰는 문서만 유지
